# Projects

The folder contains all the code for individual **Rhythms of Life** projects.

* [BD-Metabolomics](BD-Metabolomics) - exploring metabolic profile seasonal variation in bipolar disorder

* [Lifetime-Shiftwork](Lifetime-Shiftwork) - exploring the effects of early-career shiftwork on health

* [Adversity-Circadian-Rhythms](Adversity-Circadian-Rhythms) - exploring the effects of early and adulthood adversity on circadian rhythms and sleep profile

* [Chronotype](Chronotype) - investigating assocations between chronotype and diurnal variability in physiological and behavioural parameters

* [Inflammation_CR](Inflammation_CR) - exploring associations between SEP, circadian disruption, inflammation and the risk of NCD
